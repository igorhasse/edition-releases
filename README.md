# edition: instaladores e atualizações

Aqui saem as versões do **edition**, o app que grava as suas partidas de Valorant e transforma as
melhores jogadas em edits com cada kill caindo no kick da música, em 16:9 e 9:16.

- **Instalar:** baixe o instalador da versão mais recente em [Releases](../../releases/latest).
- **Atualizar:** o app se atualiza sozinho a partir deste repositório.

Ainda não há versão publicada. O código do app não fica aqui.
